🚨 PROBLÈMES CRITIQUES
--------------------------------------------------------------------

1. Overfitting Massif (ROUGE)
   Cause:   Dataset Wikipedia seul (monodomaine)
   Impact:  Val PPL = 420 vs Train PPL = 12.7
   Solution: → FineWeb-Edu (multi-domaine)
   Gain:    Val PPL 420 → 20-30 (95% improvement)

2. Landmarks Sous-Optimaux (ORANGE)
   Cause:   Penalties trop faibles (diversity 0.02, sparsity 0.001)
   Impact:  Landmarks clustered, inefficaces
   Solution: → Strengthen 5x-10x OU disable learned
   Gain:    Convergence +30%, stabilité +50%

3. Global Warmup Rapide (JAUNE)
   Cause:   Warmup 1K→5K = 4K steps seulement
   Impact:  Landmarks pas bien appris
   Solution: → Extend 5K→20K (15K steps)
   Gain:    Stabilité training, val loss réduite

4. Weight Decay Élevé (JAUNE)
   Cause:   0.1 (pour GPT-3 175B, pas SLGA 38M)
   Impact:  Sur-régularisation
   Solution: → Reduce 0.1 → 0.01 (standard)
   Gain:    Train/Val gap 3.5 → 1.0
